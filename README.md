# Petit Carnet

> A calm, beautiful, fully offline French language learning notebook.

## ✨ Quick Overview

- **963 French phrases** across 57 categories
- **58 verbs** with full conjugations (5 tenses)
- **Grammar lessons** + pronunciation guides
- **Leitner spaced repetition** system
- **Daily phrase** recommendations
- Works **100% offline**
- Supports **English, French, and Farsi**

---

## 🚀 Getting Started

```bash
git clone https://github.com/0antuosh0-create/Petit-Carne.git
cd Petit-Carne
npm install
npm run dev
```

The app opens at `http://localhost:5173`.

Build a single-file version:
```bash
npm run build
```
