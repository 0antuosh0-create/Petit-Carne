# درباره پُتی کارنه

پُتی کارنه یک دفترچه‌ی آرام و آفلاین برای یادگیری فرانسوی است — هر بار یک عبارت واقعی.

## نگاه کلی

این یک برنامه‌ی آموزشی زیبا برای یادگیری زبان فرانسوی است که شامل **۹۶۳+ عبارت** (در ۵۷ دسته‌بندی)، **۵۸ فعل معمولی و غیرمعمول** (در ۵ زمان)، **درس‌های نحوی جامع** و **راهنمای تلفظ** می‌باشد. این برنامه از سیستم تکرار متناوب (Leitner) و توصیه‌ی یک عبارت در روز برای کمک به شما در پیشرفت آهسته و بدون عجله و حفظ ردپای تمرین روزانه استفاده می‌کند.

همه‌چیز روی دستگاه شما ذخیره می‌شود — هیچ داده‌ای آپلود نمی‌شود و بدون اینترنت کار می‌کند.

## ویژگی‌های اصلی

### 📚 یادگیری (کتابخانه‌ی کارت‌های فلش)
- **۹۶۳ عبارت فرانسوی** طبقه‌بندی شده در دسته‌بندی‌هایی مانند سلام، غذا، سفر، احساسات، زبان عامیانه و غیره
- هر کارت عبارت را همراه با معنای انگلیسی، راهنمای تلفظ (`say` field) و یک یادداشت کمک‌حافظه نشان می‌دهد
- جستجوی متن کامل که تایپ‌های اشتباه و هم‌نژاد‌ها را مدیریت می‌کند
- فیلتر کردن بر اساس دسته‌بندی و سطح (A1، A2، B1)

### 🗒️ دفترچه‌ی شما
- هر عبارتی را — از کتابخانه یا ساخته‌ی خودتان — در یک دفترچه‌ی شخصی ذخیره کنید
- پایدار در سراسر جلسات با استفاده از ذخیره‌سازی مرورگر — بدون اینترنت کار می‌کند
- همه‌چیز قابل بک‌آپ است (صادرات JSON) و می‌توانید بعداً وارد کنید

### 🎯 تمرین
- مرور کارت‌های فلش با یک سیستم Leitner (جعبه‌های ۱ تا ۵)
- حالت تایپ (عبارت فرانسوی نشان داده می‌شود، شما معنای انگلیسی را تایپ می‌کنید)
- حالت چند گزینه‌ای (مربع نزن به معنای درست یا تلفظ)
- ردیابی ستاره و جشن روزانه‌ی تمرین
- تخفیف‌های شوخ‌طبعانه: کد کنامی (Konami) باعث بارش شیرینی‌های کرون‌شل می‌شود! (🥐🥖🧀✨)

### 🧵 دستور، فعل‌ها و صداها
- **دستور** – هشت درس نحوی دست‌نوشته که اکثر ساختارهای فرانسوی روزمره را پوشش می‌دهد
- **فعل‌ها** – جدول‌های کامل تحقق برای همه‌ی ۵۸ فعل‌ی که بیشتر استفاده می‌شوند در ۵ زمان: حال، گذشته‌ی ساده، گذشته‌ی ناقص، آینده و حال شرطی
- **صداها** – راهنمایی برای تلفظ زبان فرانسوی

### 📊 آمار + رابط کاربری
- داشبورد با پیشرفت، ردپا و شمارش امروزه
- سه تم زیبا (روشن، تاریک، خودکار)
- ناوبری صفحه‌نمایی، تراوش‌های صاف و طراحی واکنش‌گرا
- از سه زبان **انگلیسی (en)**، **فرانسوی (fr)** و **فارسی (fa)** پشتیبانی کامل می‌کند
- تلفظ با صدای هدفون — با صدای فرانسوی اصیل

## نکات فنی

- **فریم‌ورک:** React 19 + TypeScript 5، ساخته شده با Vite 7
- **استایل‌دهی:** Tailwind CSS 4 + سیستم طراحی سفارشی (سایه‌ها، انحنای گوشه‌ها، کارت‌های شیشه‌ای، پالت‌های رنگ)
- **ذخیره‌سازی:** مرورگر `localStorage` همراه با صادرات بک‌آپ (JSON) و وارد کردن (الگوریتم Leitner، تشخیص تکراری شدن)
- **معماری:** الگوهای UI اتمی، هوک‌های اول، صفر ML خارجی (ضرب‌کردن/تشخیص تکراری با استفاده از تطبیق رشته‌های فاصله‌دار)

## آی‌آی‌سی‌ان + دسترسی‌پذیری

رابط کاربری به طور کامل از سه زبان پشتیبانی می‌کند: **انگلیسی (en)**، **فرانسوی (fr)** و **فارسی (fa)** — برای تغییر زبانات به پنجره‌ی درباره‌ی نگاه کنید.
- فارسی از طرح راست‌به‌چپ و اعداد فارسی در ورودی‌ها استفاده می‌کند
- همه‌ی متن‌ها بومی‌سازی شده‌اند — مقدماتی، بازخورد، برچسب‌های UI و پیام‌های تخفیف‌های شوخ‌طبعانه
- خوانایی توسط فناوره‌ی صفحه‌نمایی (ARIA labels) و کلیدهای صفحه‌نمایی

## شروع به کار

```bash
# کلون کردن مخزن
cd Petit-Carnet

# نصب وابستگی‌ها
npm install

# اجرای برنامه
npm run dev
```

برنامه در `http://localhost:5173` اجرا می‌شود

### راهنمای سریع توسعه
- **تغییرات در عبارات/فعل‌ها/درس‌های دستوری** → `npm run dev` (فایل‌ها به روز هستند)
- **اجرای تست‌ها** → بررسی استفاده از Vitest / Playwright (هنوز تنظیم نشده‌اند)
- **استانداردهای کد** → Prettier + ESLint / Biome توصیه می‌شوند (اگر می‌خواهید اضافه کنید)
- **کد‌نمایش UI** → `src/components/ui.tsx` را بررسی کنید تا مجموعه‌ی مورد اشتراک UI و توکن‌های طراحی را ببینید.

## پرسش‌های متداول

### آیا به اینترنت نیاز دارم؟
رد – **پُتی کارنه بدون اینترنت کار می‌کند**. همه‌ی داده‌ها (۹۶۳ عبارت، ۵۸ فعل و دفترچه‌ی شما) در برنامه جاسازی شده‌اند و در محلی ذخیره می‌شوند.

### آیا می‌توانم یادداشت‌هایم را بک‌آپ بگیرم؟
بله. از تب **Backup** → Press “Export” → save the JSON file. To import later: load file → merge (duplicates skipped).

### آیا داده‌ها باز هستند؟
بله — کتابخانه‌ی کامل عبارت در کد ارسال شده است (`src/data/phrases.ts`). لایسنس MIT ساخته شده امکان کپی‌برداری برای سایر پروژه‌ها را فراهم می‌کند، اما پروژه‌ی فعلی عمدتاً تحت کنترل توسعه‌دهنده است.

### چرا فارسی/Farsi؟
می‌توانیم به فارسی‌زبانان اجازه دهیم بدون دخالت انگلیسی فرانسوی یاد بگیرند، که دسترسی‌پذیری را بهبود می‌بخشد و تنوع کلی را افزایش می‌دهد.

### یک عبارت در روز؟
پُتی کارنه عشق دارد که از پیشرفت آرام و بدون عجله‌ی ثابت لذت ببرد. عبارت روزانه از ۹۶۳−phrase‌ library با یک انتخاب روزانه‌ی قطعی (با این حال در صورت پریدن تو را دوباره نشان نمی‌دهد). ستاره‌ی شما فقط در صورتی ریست می‌شود که این برنامه را سه روز پشت سر بگذارید — به اندازه‌ای که یک عادت را بسازید بدون این‌که غیر واقعی باشد.

### جعبه‌های Leitner، چی هستن؟
یک الگوریتم تکرار متناوب. هر عبارت در ۵ جعبه جابجا می‌شود که بر اساس پاسخ‌های خوابیده/ناخوابیده هستند، کارت‌های سخت‌تر را برای مرور اولویت می‌دهد و کارت‌های راحت‌تر را قفل می‌کند.

### من می‌خواهم ویژگی‌های بیشتری داشته باشم.
همه‌ی پیشنهادات از طریق GitHub issues جریان می‌یابند. از آنجا که این یک پروژه‌ی سرگرمی است، ویژگی‌ها زمانی اضافه می‌شوند که با هدف این برنامه: یادگیری آرام، بدون اینترنت ارائه‌شده و با رابط کاربری زیبا هماهنگ باشند.

### کمک‌های اجتماعی؟
بله! PRها اعاده می‌شوند. مکان‌های کلیدی: ارسال عبارت‌های جدید (فرانسوی/انگلیسی/پین‌شده‌ی درست)، اضافه کردن فعل‌ها (پنج زمان)، بخش‌های دستور. هر تغییر را به صورت دستی تست کنید.
